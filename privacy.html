Privacy Policy

Effective October 20, 2026

yt-factory is a personal tool used only by the owner of the "What If History" YouTube channel to upload that owner's own videos. This policy explains what Google user data it accesses and how that data is handled.

Data accessed

  • An OAuth access token and refresh token for the owner's Google account, limited to the https://www.googleapis.com/auth/youtube.upload scope.
  • No other Google user data. The tool does not request access to email, contacts, analytics, comments, playlists, or existing videos.

How the data is used

The token is used only to upload videos created by the owner to the owner's channel, as private videos, together with the title, description, and tags the owner's pipeline generated for that video.

Storage and security

Tokens are stored in a local file on the owner's own computer with file permissions restricted to the owner's user account. They are not uploaded to any server operated by yt-factory, and there is no such server.

Sharing

yt-factory does not sell, share, or transfer Google user data to anyone. Video files and metadata are sent only to YouTube through the YouTube Data API. The use of information received from Google APIs adheres to the Google API Services User Data Policy.

YouTube API Services

yt-factory uses the YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time from Google Account → Third-party connections. Deleting the local token file removes all stored Google data from the tool.

Contact

Questions about this policy can be sent through the maintainer's GitHub profile: github.com/arietoursino-hub.
