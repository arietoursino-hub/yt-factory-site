yt-factory

A private publishing tool for the "What If History" YouTube Shorts channel.

yt-factory is a personal automation tool run by the channel owner on their own computer. It produces short alternate-history videos and uploads them to the owner's own YouTube channel as private videos, so the owner can review each one in YouTube Studio before making it public.

How it uses Google data

The tool signs in with the channel owner's Google account through Google OAuth and requests a single permission: youtube.upload, which allows it to upload videos to that channel. It does not read, change, or delete existing videos, comments, analytics, or any other account data. It is not offered to other users.

yt-factory uses the YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
